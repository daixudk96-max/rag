<threat_model>
  <threat id="T-05-01" severity="medium" stride="Tampering">
    Invalid or malicious `version_id` input could be interpolated into SQL if verification utilities bypass registry parameterization.
    Mitigation: parse version strings with `uuid.UUID`, use `PostgresRegistryWriter` methods or parameterized psycopg placeholders only, and test invalid UUID rejection.
  </threat>
  <threat id="T-05-02" severity="medium" stride="Information Disclosure">
    Validation scripts could log full database URLs or sensitive connection strings.
    Mitigation: reports may include `database_url_configured: true` and schema/version IDs, but must not write raw `DATABASE_URL`.
  </threat>
</threat_model>
