<threat_model>
  <threat id="T-05-06" severity="medium" stride="Tampering">
    Resolver refactor could accidentally alter retrieval order or select different nodes by moving content logic before ranking.
    Mitigation: resolver is called only after node selection; tests assert selected `node_id` order remains unchanged when preview source changes.
  </threat>
  <threat id="T-05-07" severity="low" stride="Repudiation">
    Summary/title fallback could be mistaken for real source content in validation artifacts.
    Mitigation: resolver tests document fallback order; optional report field may record fallback source in a later phase, but this plan preserves current `BackendHit` contract.
  </threat>
</threat_model>

      Create `llamaindex_runtime/tree/evidence_content_resolver.py` with a class:
      - `class EvidenceContentResolver:`
      - `def build_text_preview(self, *, registry: Any, version_id: UUID, node_id: UUID, span_ids: Sequence[UUID], fallback_text: str, chunk_id: UUID | None = None) -> str`

      The resolver must implement exactly this fallback order:
      1. `_text_preview_from_spans(registry, version_id, span_ids)` using `registry.query_spans_by_version(version_id)` and ordered by incoming `span_ids`.
      2. `_text_preview_from_chunks(registry, version_id, node_id, span_ids, chunk_id)` using `registry.query_vector_chunks_by_version(version_id)`, matching if `row.chunk_id == chunk_id`, or `row.node_id == node_id`, or `row.chunk_id` belongs to `_chunk_ids_for_span_ids`.
      3. `_normalize_preview_text(fallback_text)`.

      Required private helpers:
      - `_text_preview_from_spans(...) -> str`
      - `_text_preview_from_chunks(...) -> str`
      - `_chunk_ids_for_span_ids(...) -> set[UUID]`
      - `_coerce_uuid(value: Any) -> UUID | None`
      - `_normalize_preview_text(text: str, max_length: int = 1600) -> str`

      Error handling:
      - Catch exceptions from missing registry methods and return empty string for that source.
      - Do not mutate input `span_ids` or node dictionaries.
      - Do not import `ReasoningTreeBackend` or `PageIndexTreeAdapter` from this module.
    </action>
