<objective>
Create the Phase 8 preflight gate that decides whether matched validation may proceed. The gate consumes Phase 7 DB evidence-chain artifacts and fails closed when Phase 7 remains `DB_EVIDENCE_BLOCKED`, so Phase 8 cannot collect judgments or publish a Level assessment on a missing or inconsistent evidence chain.
</objective>

<must_haves>
  <truths>
    <truth>REQ-P8-MATCHED-VALIDATION-RERUN cannot start matched retrieval until Phase 7 evidence is `DB_EVIDENCE_READY` or a fresh DB-backed rerun proves equivalent readiness.</truth>
    <truth>When Phase 7 remains `DB_EVIDENCE_BLOCKED`, Phase 8 writes `EVIDENCE_CHAIN_REMEDIATION_REQUIRED` and routes to evidence-chain remediation instead of judgment collection.</truth>
    <truth>The preflight gate never prints, logs, or serializes the raw `DATABASE_URL`; it records only booleans, status strings, active version IDs, and blocker reason codes.</truth>
    <truth>Level 2 remains authoritative before any matched DB-backed Level assessment exists.</truth>
  </truths>
  <key_links>
    <link from="verification/phase7-db-backed-evidence-chain-rerun/evidence_chain_delta.json" to="verification/phase8-matched-validation-rerun/phase8_preflight_status.json" via="Phase 7 final classification controls Phase 8 entry" pattern="final_classification|DB_EVIDENCE_READY|DB_EVIDENCE_BLOCKED" />
    <link from="verification/phase7-db-backed-evidence-chain-rerun/db_readiness.json" to="verification/phase8-matched-validation-rerun/remediation_required.json" via="sanitized DB blocker propagation" pattern="database_url_configured|blocking_reasons|database_url_not_configured" />
  </key_links>
</must_haves>

<threat_model>
  <threat id="T-08-01" severity="high" stride="Tampering">
    Phase 8 could proceed using stale or blocked evidence-chain artifacts and create another invalid Level assessment.
    Mitigation: `phase8_preflight.py` must require `final_classification == "DB_EVIDENCE_READY"` before matched retrieval; otherwise it writes `status: "EVIDENCE_CHAIN_REMEDIATION_REQUIRED"` and exits non-zero.
  </threat>
  <threat id="T-08-02" severity="high" stride="Information Disclosure">
    DB preflight code could leak a raw connection string while trying to explain why DB access is blocked.
    Mitigation: propagate only `database_url_configured`, `connection_status`, `active_version_id`, and `blocking_reasons`; never serialize or print `os.getenv("DATABASE_URL")`.
  </threat>
</threat_model>
