<threat_model>
  <threat id="T-08-03" severity="high" stride="Tampering">
    A matched validation rerun can be invalidated by mixing retrieval output from one active version with judgment rows from another corpus or older run.
    Mitigation: create a Phase 8 output directory, generate retrieval and template in the same command, record `active_version_id`, and refuse to read or copy existing completed judgments.
  </threat>
  <threat id="T-08-04" severity="medium" stride="Repudiation">
    A retrieval run with partial failures could later be mistaken for a complete 20-query validation run.
    Mitigation: write `validation_status.json` with `query_count_expected: 20`, `query_count_completed`, `total_hit_rows`, `retrieval_failures`, and `status` values `MATCHED_RETRIEVAL_READY` or `MATCHED_RETRIEVAL_BLOCKED`.
  </threat>
</threat_model>
