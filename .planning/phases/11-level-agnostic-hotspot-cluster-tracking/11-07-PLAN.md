<design_decisions>
- 新增 selector，不直接替换、删除或重命名 `ClusterHotspotSelector`。旧 selector 作为 `cluster` 回滚路径保留。
- 推荐策略名固定为 `hybrid_cluster`；本计划不再允许 `retrieval_distribution` 作为并行备选名，避免 config/tests/validation 出现命名漂移。
- `route_subtree` 必须继续可用，作为 Phase 10 回滚路径。
- `cluster` 必须继续可用，作为 Phase 11 初版 cluster selector 回滚路径。
- 不允许在生产评分逻辑中硬编码项目关键词。`semantic_distribution.py` 中的 `expected_keywords` / `forbidden_keywords` 必须删除，或隔离到测试/验证 artifact 中；生产 selector 不得引用这些名字或 p6 专用词表。
- 新 selector 的目标不是“让 DNA 查询过关”，而是让任意领域查询通过可解释的 retrieval distribution 信号选择局部热点。
</design_decisions>

<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| query text -> keyword/BM25 seam | User/business query text crosses into DB-backed span lookup and must be parameterized/sanitized. |
| vector/keyword/rerank evidence -> selector scoring | Heterogeneous scores can bias hotspot selection if not normalized and bounded. |
| env/config -> runtime selector | Selector name changes runtime behavior and must preserve rollback values. |
| validation expected terms -> production code | Validation assertions must not leak into production scoring as hardcoded project keywords. |
| GitNexus impact -> commit readiness | HIGH/CRITICAL affected runtime paths must be surfaced before edits/commit readiness. |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-07-01 | Tampering | hybrid score fusion | mitigate | Normalize vector, keyword/BM25, rerank, and distribution scores before fusion; add tests for scale dominance. |
| T-11-07-02 | Information Disclosure | validation/runtime artifacts | mitigate | Do not serialize raw `DATABASE_URL`, embeddings, or secrets; grep artifacts for connection strings before readiness. |
| T-11-07-03 | Denial of Service | keyword span lookup | mitigate | Bound keyword/BM25 candidate limits; reuse existing DB query seam; fail closed/degrade gracefully if unavailable. |
| T-11-07-04 | Repudiation | hardcode cleanup | mitigate | Add anti-hardcode tests proving production selector does not use p6 `expected_keywords` / `forbidden_keywords`. |
| T-11-07-05 | Spoofing | selector env value | mitigate | Validate selector value against explicit allowlist: `route_subtree`, `cluster`, and the new strategy. |
| T-11-07-06 | Elevation of Privilege | reranker seam | mitigate | Reranker limited to optional in-memory `rerank_scores`; no external calls or secrets in this plan. |
| T-11-07-07 | Tampering | runtime path edits | mitigate | Run GitNexus impact before edits and detect-changes before readiness; preserve rollback selectors. |
