<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Corpus → entity_mentions | A single invalid document must not leak partial rows for that document/version. |
| Changed desired set → existing rows | A shrinking selected set must remove only E2b-owned rows (mentions, link ownership, and bridges with explicit ownership and no remaining owner); manual/legacy/foreign/unowned rows must survive. |
| Acceptance runner → DB | Only a strict loopback disposable target may be connected. |
| Concurrent runs → materialization | Overlapping runs must serialize without duplicate rows. |
| E2b ↔ E2a | Same-document/version runs must serialize on E2a's shared advisory key or they corrupt each other's rows. |
