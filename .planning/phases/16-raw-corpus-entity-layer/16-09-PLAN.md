<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Document/version → entity_mentions | A single invalid span must not leak partial rows for that document/version. |
| Changed desired set → existing rows | Shrinking a selected set must remove only E2b-owned rows; manual/legacy/foreign rows must survive. |
| Primary transaction → failure audit | Failure evidence must be durable on a fresh connection without reusing Phase 15 audit. |
| Mentions → link tables | E2b must never write chunk_entity_links and must write node_entity_links only for resolved entities with proof of ownership for deletions. |
| E2b ↔ E2a concurrency | Both layers must serialize on the SAME advisory key for the same document/version or they corrupt each other's rows. |
