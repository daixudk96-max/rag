## Trust Boundaries

| Boundary | Description |
|---|---|
| Migration SQL → existing schema | A schema-gap migration can silently alter inherited tables, change the node_entity_links PK, or reuse Phase 15 audit constraints. |
| Provenance + owner-scope columns → durable rows | Missing or unconstrained provenance or an incorrect owner-scope value makes desired-state reconciliation unsafe (deleting the wrong rows). |
| Bridge ownership ledger → node_entity_links | Without a typed ownership proof, stale cleanup could delete manual/legacy bridges or E2b could claim foreign bridges. |
