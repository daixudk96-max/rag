# 基本信息

内蒙古自治区卫生健康委员会是内蒙古自治区人民政府组成部门，负责全区卫生健康工作的行政管理。

# 主要职责

- 负责全区卫生健康政策制定
- 医疗机构监督管理
- 公共卫生事件应急处理
- 医疗卫生人才培养

# 组织架构

下设多个处室，包括：
- 医政医管处
- 疾病预防控制处
- 基层卫生健康处
- 卫生应急办公室
