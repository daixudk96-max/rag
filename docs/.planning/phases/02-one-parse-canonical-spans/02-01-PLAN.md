# Phase 2 Plan — One Parse -> Canonical Spans

## Goal
通过 Docling 一次解析生成可追溯的 canonical spans，并把解析结果稳定写入 PostgreSQL registry 主干。

## Scope
### In
- Docling wrapper
- normalization helpers
- span generator
- PostgreSQL 写入 canonical_spans
- page_no / heading_path / offsets 的稳定性验证

### Out
- Keyword path 实现
- Vector path 实现
- Neo4j 图层
- Deep Hybrid path
- Reranker

## Tasks
1. 用 TDD 写 `DoclingWrapper` 的 contract 测试，再实现 wrapper
2. 用 TDD 写 `SpanGenerator` 与 `normalization` 的测试，再实现 spans 生成逻辑
3. 用端到端测试证明：PDF -> Docling -> spans -> PostgreSQL 可写通

## Exit Criteria
- 相同 normalization contract 下解析结果稳定
- 每个 span 都有 page_no / heading_path / offsets
- spans 可写入 canonical_spans 表
- 端到端测试通过

- `pytest tests/test_phase2_e2e.py -q`
