## Goal
在现有 Tree / Vector 主干上实现命中分布分析器，输出集中/分散指标与最小扩展决策建议。

## Scope
### In
- hit_distribution types / analyzer / decision / collector
- `/query/analyze` API
- Vector->Tree 单路命中分布分析

### Out
- Deep Hybrid 主链
- Reranker
- Graph 在线依赖

## Tasks
1. 写 analyzer / decision 的 RED 测试
2. 实现核心聚合与 CV/Entropy 计算
3. 实现 collector 和 `/query/analyze`
4. 跑 API 与 full suite

## Exit Criteria
- 能输出 `cv / entropy / decision`
- 无命中时返回 `no_hits`
- 不依赖 Neo4j 在线
