# Phase 3 Plan — Keyword Path

## Goal
在 PostgreSQL 主干上建立 Keyword path，支持精确术语检索，并保证返回结果可回 `span_id / doc_id / version_id / page_no / heading_path`。

## Scope
### In
- PostgreSQL FTS / trigram 索引
- SQL 检索函数
- Python 检索层
- 最小 API 入口
- 精确术语测试样例

### Out
- Vector/Keyword 融合
- Query classifier
- Reranker
- Deep Hybrid path

## Tasks
1. 先写 Keyword path 的 RED 测试
2. 扩展 schema：增加 FTS / trigram / SQL 函数
3. 实现 Python keyword search 模块
4. 实现 `/query/keyword` 最小 API
5. 跑样例与端到端测试

## Exit Criteria
- `PM2.5`、标准号、节目名等样例命中
- 返回字段带 `span_id / page_no / heading_path`
- 默认只查 active version
- Phase 3 测试通过
