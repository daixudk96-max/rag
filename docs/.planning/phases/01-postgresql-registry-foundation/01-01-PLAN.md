<interfaces>
doc_id: UUID — 逻辑文档身份，跨版本稳定
version_id: UUID — 文档版本身份，绑定 normalization_contract_id
span_id: UUID — 规范证据身份，绑定 version_id
chunk_id: UUID — 向量视图身份，绑定 version_id
normalization_contract_id: UUID — span 生成契约

关键外键链路:
  documents ← document_versions(doc_id)
  normalization_contracts ← document_versions(normalization_contract_id)
  document_versions ← canonical_spans(version_id)
  document_versions ← vector_chunks(version_id)
  canonical_spans ← vector_chunk_spans(span_id)
  vector_chunks ← vector_chunk_spans(chunk_id)

关键约束:
  UNIQUE (doc_id, version_no) ON document_versions
  UNIQUE (doc_id, content_hash) ON document_versions
  每篇文档最多一个 is_active=TRUE 的 version（应用层强制或部分索引）
</interfaces>
</context>

       - 部分唯一索引：CREATE UNIQUE INDEX idx_document_versions_one_active ON document_versions(doc_id) WHERE is_active = TRUE; 确保每篇文档最多一个 active version
