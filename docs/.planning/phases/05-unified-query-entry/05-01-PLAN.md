# Phase 5 Plan — Unified Query Entry

## Goal
提供统一 `/query` 入口，在 Keyword path 与 Vector path 之间做最小路由，并返回统一结构化证据。

## Scope
### In
- UnifiedQueryResult
- query classifier
- `/query` endpoint
- 统一证据输出

### Out
- Deep Hybrid
- Reranker
- 多路融合

## Tasks
1. 先写 unified output 与 classifier 的 RED 测试
2. 实现统一输出结构和最小路由器
3. 扩展 `/query`
4. 跑端到端与 API 冒烟

## Exit Criteria
- `/query` 可用
- 精确术语自动走 keyword
- 语义问题自动走 vector
- 输出带完整可追溯证据
