# Phase 7 Plan — Graph Path

## Goal
引入最小 Neo4j graph projection，支持 entity / relation / evidence links，并提供 `/query/graph` 入口。

## Scope
### In
- PostgreSQL entities / relations / evidence_links
- Neo4j container + connection
- entity / relation / evidence projection
- graph query
- span resolver
- `/query/graph` API

### Out
- Deep Hybrid
- HitDistributionAnalyzer
- Reranker
- 复杂 entity canonicalization

## Tasks
1. 先写 graph schema / projection / query / api 的 RED 测试
2. 增加 Postgres graph schema migration 与 Neo4j 服务
3. 实现 graph projection / query / span resolver
4. 跑 integration + e2e + full suite

## Exit Criteria
- graph path 可查 entity / relation / evidence
- 结果能稳定回 `span_id / version_id / doc_id`
- 与 Keyword / Vector / Tree 共用同一 provenance 主干
