# Phase 4 Plan — Vector Path

## Goal
在 PostgreSQL + pgvector 上建立最小 Vector path，证明 `canonical_spans` 可以组合成 `vector_chunks`，并支持轻量语义检索，返回结果可回 `chunk_id / span_id / page_no / heading_path`。

## Scope
### In
- pgvector schema 扩展
- spans -> vector_chunks 组合
- 轻量 embedding 生成
- vector search 查询
- `/query/vector` API

### Out
- Neo4j 图层
- Qdrant / Milvus 独立向量库
- Deep Hybrid
- Reranker

## Tasks
1. 写 Vector path 的 RED 测试
2. 增加 pgvector migration
3. 实现 chunker / embedder / loader / search
4. 扩展 `/query/vector`
5. 跑 API 与端到端测试

## Exit Criteria
- 轻量语义 query 能召回相关 chunks
- 返回结果带 `chunk_id / span_ids / page_no / heading_path / score`
- 与 Keyword path 共用同一 version / span 主干
