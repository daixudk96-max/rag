# Phase 11 Plan — Production Hardening

## Goal
在不依赖新的外部服务授权前提下，硬化现有 PostgreSQL / API / Hybrid 主干：连接池、输入边界校验、统一错误处理、结构化日志、Neo4j 健康检查。

## Scope
### In
- PostgreSQL connection pool
- API validation
- unified error handling
- structured logging
- /health and /health/neo4j

### Out
- 认证 / 授权
- 速率限制
- 外部日志平台
- Neo4j 运行时授权获取

## Tasks
1. 写连接池 RED 测试并实现 pool
2. 写 validation / error RED 测试并实现
3. 写 logging / health RED 测试并实现
4. 跑全量回归

## Exit Criteria
- get_connection 基于 pool
- 空 query / 越界参数返回 422 JSON
- 数据库异常返回 500 JSON
- 输出结构化日志
- /health 与 /health/neo4j 可用
